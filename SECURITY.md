# Security policy

This policy covers vulnerabilities **in GQLSleuth itself**, including unintended requests,
consent bypasses, credential exposure and unsafe processing of untrusted target data.
Vulnerabilities discovered in a third-party target belong to that target's owner or authorized
disclosure program, not this repository. Test only systems you are explicitly authorized to assess.

## Supported versions

The current development version is 0.1.0; no v1.0 release is declared. Maintainers review security
reports against the current development tree. After publication, the latest released version
will be the supported version; older versions receive best-effort review without a backport
guarantee. No response-time or long-term-support guarantee is currently offered.

## Private reporting

The intended private channel is **GitHub private vulnerability reporting** for
[Tomas-Ortiz/gqlsleuth](https://github.com/Tomas-Ortiz/gqlsleuth/security).
Maintainers must enable that repository setting before relying on this route. Its availability
has not been verified as part of this documentation change. If the Security tab offers
**Report a vulnerability**, use it. If it does not, open only a non-sensitive request asking
maintainers to enable private reporting; do not disclose the vulnerability, exploit or artifacts
in a public issue. No dedicated security email address is currently documented.

Include the affected version/commit, Python/OS, relevant command options with fake values,
expected and observed behavior, impact, and a minimal mocked or loopback reproduction. Explain
any required consent/configuration and whether the issue affects confidentiality or request
boundaries. Never include real credentials, customer information or unauthorized target data.

Please coordinate remediation and disclosure with maintainers before publishing details.
Do not conduct disruptive testing to prove a report. Reports generated by GQLSleuth can retain
exact variables and raw application evidence; keep them private and share only the minimum
necessary reproduction through an agreed private channel.
